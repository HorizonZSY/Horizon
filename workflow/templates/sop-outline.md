# SOP / PS 结构

## A. 美国经济学风格 SOP（研究兴趣导向）

比例参考 Gentzkow–Shapiro 实验室手册（gentzkow/lab-manual-archive wiki 中的 PhD Applications 页）：

| 部分 | 比例 | 内容 |
|---|---|---|
| 个人叙述 | < 10% | 为什么走研究这条路，只用一个具体经历（申请者本人写） |
| 过往经历 | 10–20% | 课程训练、RA、实习中与研究能力相关的部分 |
| 独立研究 | 20–30% | 毕业论文等：你提出了什么问题、如何解决、学到了什么 |
| 拟开展的研究 | > 50% | 1–2 个具体项目：问题、设计、数据、为什么在这个项目做 |

不要重复 CV 里已有的信息；每一段都应回答"这说明我能做研究的哪一种能力"。

## B. 英国 / 香港 Personal Statement（项目导向）

通常更短（以官网字数为准），与 research proposal 分工：proposal 讲研究本身，PS 讲人与项目的匹配。

1. 开头：研究方向一句话 + 为什么申请这个项目（具体到导师、研究中心或训练课程）
2. 训练基础：计量、编程、数据经验，每项配一个产出证据
3. 研究经历：毕业论文的问题、方法、发现，及其与 proposal 的关系
4. 研究计划摘要：2–3 句，指向 proposal
5. 职业目标：PhD 之后的方向，与项目培养目标的衔接

## 通用检查

- 个人经历与动机由申请者本人写
- 每个主张有证据（课程、项目、产出）
- 无强度膨胀修辞；无"不是…而是…"式句子
- 与 proposal、CV 的事实（日期、方法、数据）一致
- 在字数上限内
